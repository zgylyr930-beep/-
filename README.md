# 沉浸式网页翻译助手

一个 Chrome Manifest V3 扩展：识别英文正文，并在原位置替换为简体中文。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `page-translator`。
5. 点击扩展图标，进入“DeepSeek API 设置”，填写自己的 API Key 并测试连接。
6. 打开普通网页并刷新，然后点击工具栏里的扩展图标。

## 功能

- 自动识别英文正文段落并替换为中文，翻译后不保留英文。
- 专注英文翻译为简体中文，自动跳过中文及没有足够英文内容的段落。
- 右键翻译选中的文本。
- 一键移除译文、恢复原页面。
- 使用 6 路并发和本页翻译缓存，在稳定性与速度之间取得平衡。
- 网页右下角浮球可一键翻译或恢复原文；可选开启英文网页自动翻译。
- 浮球支持鼠标、触控板和触屏拖拽，会记住位置并始终限制在可视区域内。
- 默认使用自嘲熊动图作为浮球，可在设置页上传自己的 PNG、JPEG、WebP 或 GIF 图片。
- 译文直接替换原元素内容，继续沿用网站原有字体、字号、行距、宽度和响应式排版。
- 只替换文字节点，保留链接、图片、粗体、按钮、输入框和网页事件。
- 自动模式可识别一分钟内延迟加载的英文正文。

## 说明

当前版本直接调用 DeepSeek 官方 API，默认使用关闭思考模式的 `deepseek-v4-flash`。API Key 只保存在 `chrome.storage.local`，不会写进源码或通过 Chrome 账号同步。Chrome 内置页面、扩展商店和部分受保护页面不允许内容脚本运行。
